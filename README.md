
## 📚 Contenido del curso

### 🟦 Parte 1 — Programación Orientada a Objetos en C++
> Fundamentos, clases, herencia, polimorfismo, persistencia y buenas prácticas.

### 🟨 Parte 2 — Frontend Web y POO en JavaScript
> HTML, CSS, JavaScript, DOM, eventos y objetos del lado del cliente.

### 🟩 Parte 3 — Integración Backend · Frontend
> Conexión entre C++ (backend) y la interfaz web, APIs y flujo completo.

## 🎯 Objetivo

Construir un sistema completo aplicando **Programación Orientada a Objetos**, desde sus fundamentos en C++ hasta su integración con una interfaz web moderna en JavaScript.

> 💡 *Un curso progresivo: del paradigma a la práctica, del backend a la interfaz.*
